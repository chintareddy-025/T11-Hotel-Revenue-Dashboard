## Development Approach
This is a no-code / AI-assisted project. The supplied Excel workbook was used as the source of truth. AI was used iteratively for dataset inspection, KPI definitions, verification, dashboard structure, channel analysis, capacity testing, strategy development and documentation.

No Jupyter Notebook, VS Code project, or fabricated coding workflow is claimed.

## Responsible AI
The dataset is synthetic. Numerical outputs were independently reconciled to the source workbook. The AI Use Log documents the iterative development process.

## Key Recommendation
Increase direct and corporate demand where feasible, continue OTA channels selectively for incremental demand, monitor realised value and cancellations together, and use 90% capacity as a review trigger rather than an automatic overbooking rule.
